Das Wichtigste für morgen

Metall + Säure → Salz + Wasserstoff

Beispiel: Magnesium + Salzsäure → Magnesiumchlorid + Wasserstoff.

Säure + Lauge → Salz + Wasser

Beispiel: Salzsäure + Natronlauge → Natriumchlorid + Wasser.

Metalloxid + Säure → Salz + Wasser

Beispiel: Magnesiumoxid + Salzsäure → Magnesiumchlorid + Wasser.
