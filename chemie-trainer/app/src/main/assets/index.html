Das musst du über Salze wissen

1. Was ist ein Salz?

Eine Ionenverbindung aus positiv geladenen Kationen und negativ geladenen Anionen. Insgesamt ist das Salz elektrisch neutral.

2. Wie entsteht ein Salz?

Zum Beispiel reagieren Metall-Atome mit Nichtmetall-Atomen. Es entstehen Ionen, die sich elektrostatisch anziehen.

3. Ionenladung

Hauptgruppen helfen: Na⁺, Mg²⁺, Al³⁺; Halogenide meist Cl⁻, Oxid O²⁻, Sulfid S²⁻.

4. Formel bilden

Die Gesamtladung muss null sein. Kleinste ganzzahlige Anzahl der Ionen verwenden.

Salzformeln – Beispiele

NatriumchloridNaCl

Na⁺ + Cl⁻ → 1:1

MagnesiumchloridMgCl₂

Mg²⁺ + 2 Cl⁻ → 1:2

AluminiumoxidAl₂O₃

2 Al³⁺ + 3 O²⁻ → Ladungen +6 und −6

CalciumcarbonatCaCO₃

Ca²⁺ + CO₃²⁻ → 1:1

NatriumsulfatNa₂SO₄

2 Na⁺ + SO₄²⁻ → 2:1

Reaktionen verstehen

Neutralisation

Säure + Lauge → Salz + Wasser. Beispiel: HCl + NaOH → NaCl + H₂O

Metall + Nichtmetall

Beispiel: 2 Na + Cl₂ → 2 NaCl

Wichtig!

Beim Ausgleichen einer Reaktionsgleichung nur Koeffizienten vor die Formeln setzen – niemals die Indizes in den Formeln verändern.
